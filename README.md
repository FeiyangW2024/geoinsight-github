# GeoInsight · 地图数据与候选区域初筛

GeoInsight 将三个候选区域的空间数据查询、同口径比较、证据核对和报告输出组织成一个工作流程。以北京咖啡门店初筛为应用场景，支持形成优先考察区域、两条选择依据及一项待核实风险。

## 产品能力

- 交互地图：拖动、缩放、点击选点及 WGS84 坐标输入。
- 三点比较：1 km 范围内咖啡记录、办公建筑、购物中心、地铁入口；3 km 内最近收录入口的直线距离。
- 数据治理：四类 POI 映射、对象层级、去重与异常保留；指标关联源对象 ID 和规则版本。
- 决策交付：依据核对、任务计时、Markdown 初筛报告及 JSON 分析数据导出。
- 可访问操作：坐标表单、键盘地图控制和移动布局。
- 浏览器 WebMCP：读取分析与更新候选点，复用相同页面状态。

## 本地运行

本项目是静态网页，无构建步骤或运行时外部 API。请使用 HTTP 服务打开，避免直接双击 HTML：

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

在本机使用已有 conda 环境时：

```bash
conda run -n py312 --no-capture-output python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

访问 http://127.0.0.1:8765/ 。输入在当前浏览器页面内处理，刷新会清空，请先导出报告。

## 数据与计算

北京 OSM / Geofabrik 快照：2026-09-30T20:22:42Z；规则版本 strict-v0.2。核心数据共 2,354 条：咖啡 431、办公建筑 595、购物中心 216、地铁入口 1,112。未纳入记录保留供核对。

分析窗口为经度 116.10–116.75、纬度 39.65–40.18。面状设施使用面内代表点；距离使用 WGS84 椭球测地计算。道路与 POI 来自同一冻结快照，不请求在线瓦片或商业地图数据。

统计反映快照内符合分类规则的记录；未收录不等于现实不存在。入口距离是直线距离。产品支持考察初筛，实际营业、客流和租金需另行核实。

## 核验

```bash
node tests/check_core.mjs
```

仓库包含独立参考结果。若重建参考，需要 Python 的 pyproj：

```bash
conda run -n py312 python tests/build_reference.py
node tests/check_core.mjs
```

12 个候选点的空间指标与独立 pyproj 结果一致；104 个距离案例包含 1 km / 3 km 边界，最大误差低于 0.02 m。该结果验证计算一致性，不等同于覆盖率或用户效率指标。

## 目录

- dist/：可直接部署的网页、样式、规则计算与冻结数据。
- tests/：独立参考数据、计算检查与开发阶段交互检查记录。
- docs/：Phase 0 schema 与分类映射设计草案；部署版规则以 dist/data/meta.json 和 POI 记录为准。
